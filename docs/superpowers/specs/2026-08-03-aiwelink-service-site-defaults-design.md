# AIWeLink 服务站点默认项与流量配置标签顺序设计

## 目标

统一运营管理中服务站点的展示顺序和默认选择，并交换访问流量分析中的“活动管理”与“渠道管理”标签位置。

## 服务站点规则

- 服务站点优先级固定为 `aiwelink`、`aigclink`。
- 用户同时拥有两个站点权限时，所有服务站点选择框按 `AIWeLink`、`AIGCLink`、`全部站点` 的顺序展示。
- 进入运营概览、内部人员、额度与兑换码、待分类页面时，默认选择 `AIWeLink`，不再默认选择“全部站点”。
- 新建内部人员、生成兑换码、调整余额和新增换算比例时，默认选择 `AIWeLink`。
- 用户没有 `aiwelink` 权限时，不显示无权限站点，默认选择其第一个有权限的站点。
- 用户没有任何运营站点权限时，继续显示现有无权限状态。
- 用户手动切换站点后，不在普通加载或数据刷新时强制切回 `AIWeLink`。
- “全部站点”继续保留，只作为用户主动选择的筛选项。
- 权限管理页面中 `AIWeLink` 列保持第一，但本次改动不会自动授予任何站点权限。

## 标签顺序

访问流量分析的标签顺序调整为：

1. 流量概览
2. 推广链接
3. 活动管理
4. 渠道管理
5. 站点接入

仅交换“活动管理”和“渠道管理”的展示位置；标签键、页面内容、表单、接口和数据关系保持不变。

## 实现边界

- 服务站点默认规则在前端集中实现，不改变后端未传 `site_id` 时的查询语义。
- 不修改用户权限数据、不扩大可见站点范围。
- 不改变活动必须归属渠道的业务关系。
- 不修改访问流量分析内推广渠道的排序或默认值。

## 验收标准

1. 同时拥有 `aiwelink` 和 `aigclink` 权限时，各运营页面首次打开均选中 `AIWeLink`。
2. 服务站点下拉中 `AIWeLink` 位于 `AIGCLink` 和“全部站点”之前。
3. 仅拥有 `aigclink` 权限时默认选择 `AIGCLink`，页面中不出现 `AIWeLink`。
4. 各创建弹窗默认选择当前优先站点 `AIWeLink`，无权限时正确回退。
5. 访问流量分析中“活动管理”显示在“渠道管理”之前。
6. 相关前端测试和生产构建通过。
