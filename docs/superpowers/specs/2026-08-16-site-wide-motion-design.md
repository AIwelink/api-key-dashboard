# 全站流畅动效设计

## 目标

AIwelink 管理面板是高密度运营工具。动效用于说明页面层级、数据正在同步和操作已经生效，不用于装饰。此次覆盖全站页面切换、按钮、提示、弹层和加载反馈，并重点优化 API 账号池状态、访问流量分析、运营管理三页。

## 设计方向

沿用现有浅色工作台与工作计划页的克制动效，不更换配色和字体。唯一视觉签名是页面顶部的“数据同步轨”：后台请求超过短暂阈值后出现一条细线，保留当前内容并传达同步状态；数据就绪后，各主要内容带以短距离、分阶段方式进入。

不引入 GSAP、Framer Motion 或持续装饰动画。Vite 与 CSS 动画足以完成本次体验，React 仅提供真实加载状态和稳定 class。

## 动效系统

```css
--motion-fast: 160ms;
--motion-standard: 220ms;
--motion-drawer: 280ms;
--motion-page: 420ms;
--ease-enter: cubic-bezier(.16, 1, .3, 1);
--ease-state: cubic-bezier(.22, 1, .36, 1);
```

- 路由舞台只做 `opacity` 过渡，内容带使用 `opacity + translate3d(0, 8px, 0)`，最长 420ms。
- 内容分段：标题、工具栏、指标带、数据区按 40-60ms 间隔进入。
- 后台刷新：旧内容保持可读，只显示同步轨与轻微状态变化。
- 首次加载：稳定高度的骨架/状态面，避免表格与页面跳动。
- 按钮：按下时轻微下移，禁用状态不播放。
- 弹层与 Toast：遮罩淡入，内容短距离进入；不改变焦点管理。
- 表格：只对首批可见行做一次错峰，其余行同一延迟，避免长列表动画拖尾。

动画只使用 `opacity` 与 `transform`。不动画布局尺寸、大面积阴影、模糊或整张表格的持续效果。

## 全站衔接

当前路由页面放入以 view 为 key 的 `.app-view-stage`。导航切换后新页面从最终布局附近进入，动画期间仍可点击和聚焦。Toast 留在路由舞台之外，避免切页时被重新挂载。

侧栏当前项通过伪元素短距离滑入；通用按钮增加按压反馈；已有 modal、dialog、drawer 和 backdrop 只添加视觉过渡，不修改 DOM 生命周期和关闭逻辑。

### 全页面内容编排

所有可访问路由共享 `.site-motion-scope`，并通过 `data-view` 保留当前页面身份。除已有独立编排的工作计划、API 账号池状态、访问流量分析和运营管理外，普通页面的一级标题、工具栏、摘要、表单和数据面板按最多四档短延迟进入；切换标签时，只动画新标签内容，不移动标签栏。进入结束后 transform 必须恢复为 `none`，包含 fixed 遮罩或移动端浮层的内容带在浮层挂载时立即退出位移动画，保证遮罩始终相对视口定位。

表格与通用 `.list`、业务 `*-list` 只错峰前 6 个可见项目，后续项目不产生长尾等待。加载、空数据和具有 `role="alert"` 的错误反馈在挂载时使用更短的状态过渡，不使用宽泛的错误类名子串匹配。弹窗、抽屉和浮层继续使用各自的专属动画，并从通用内容编排中排除，避免动画叠加。此规则覆盖上传、待办、账号、账号池管理、自动补号、客户站点、流量配置、Agent、系统管理、在线状态、用户和日志等全部页面。

## 重点页面

### API 账号池状态

- 页面根节点暴露 `aria-busy`、首次加载与后台刷新 class。
- 标题工具栏、分组条、健康摘要、账号列表分阶段进入。
- 账号列表首次加载使用稳定的三行骨架，不再用单行“加载中...”造成表格跳动。
- 同步账号池与前端数据刷新期间保留现有指标和账号列表。

### 访问流量分析

- 工作区和标签内容使用短入场过渡，切换标签时不移动标签栏。
- 配置页首次加载使用结构化状态面，避免纯文本突然替换整个内容区。
- 概览刷新时保留已有数据；指标、漏斗和数据表按内容带进入，不动画每个单元格。

### 运营管理

- 查询栏、指标带、生命周期带、数据区分阶段进入。
- 刷新源数据时使用同步轨，旧概览保持可读。
- 空表加载状态使用稳定状态面；首批可见行在数据到达时一次进入。
- 兑换码结果层与普通弹层共享同一进入节奏。

## 可访问性与性能

- 真实加载容器使用 `aria-busy`，加载提示使用 `role="status"`。
- `prefers-reduced-motion: reduce` 下关闭所有非必要 animation/transition，同步文案继续可见。
- 页面切换不改变焦点顺序；弹层关闭后的焦点返回逻辑保持不变。
- 移动端不产生页面级横向滚动，表格只在自身滚动容器内横向滚动。
- 同步轨延迟约 100ms 显示，减少快速请求造成的闪烁。

## 验收

- 全站路由切换、通用按钮、Toast 和弹层具有一致且短促的反馈。
- 每个可访问页面的一级内容、标签内容、首批表格/列表项目以及加载、空态和错误态均有连续反馈。
- 三个重点页面首次加载、后台刷新、标签切换和数据就绪均连续，无白屏或明显布局跳动。
- 正常模式与 reduced-motion 模式均可完成所有操作。
- 桌面与手机无内容重叠、页面级横向溢出或控制台错误。

## 设计自检

本方案的同步轨来自后台管理工具的真实数据流，不是可复用到任意页面的装饰。视觉风险集中在一个有业务含义的元素上，其余动效保持安静。相比在每张卡片上增加浮动、光效或复杂曲线，这套节奏更符合账号池、流量和运营数据需要持续扫描与重复操作的场景。
