# 流量分析页滚动与紧凑布局设计

## 目标

修复访问流量分析页中数据表格截获纵向鼠标滚轮的问题，并在不减少信息、不改变统计口径的前提下提高单屏数据密度。

## 滚动行为

- 页面是唯一的纵向滚动容器。
- 所有数据表格容器仅处理横向溢出，不设置固定高度或纵向滚动。
- 移除会阻止滚动继续传递到页面的 `overscroll-behavior: contain`。
- 宽表继续保留原生横向滚动条、触控板横向滚动和 `Shift + 滚轮` 操作。
- 表格容器继续保留 `role="region"`、可聚焦能力和可见焦点样式，保证键盘用户能够访问宽表。

## 紧凑布局

- 页面区块间距由 16px 收紧到 12px。
- 筛选区减少内边距、字段间距和控件高度，桌面端仍保持四列，现有响应式断点不变。
- 主指标区降低最小高度和数字字号，但保持两项主指标的视觉优先级。
- 上下文指标、能力提示、区块标题和注册汇总减少高度与内边距。
- 表格表头与数据行减少垂直内边距和行高；缩短可安全收紧的列宽，推广链接表和用户归因表仍允许横向滚动。
- 数据质量区同步收紧间距，不改变展开、折叠及内容结构。

## 范围边界

- 不修改后端接口、统计字段、筛选逻辑、分页逻辑或数据内容。
- 不增加自定义滚轮事件处理，不把普通纵向滚轮强制转换为横向滚动。
- 不移除字段或隐藏信息，不改变移动端现有的单列/双列布局规则。

## 验收标准

1. 鼠标位于任意表格区域时，普通滚轮能够继续上下滚动整个页面。
2. 表格容器计算样式为横向可滚动、纵向可见，且不再有 440px 高度限制。
3. 宽表仍可通过原生横向滚动、触控板或 `Shift + 滚轮` 查看全部列。
4. 桌面和移动视口均无全局横向溢出，文字不遮挡，表格内容不被裁切。
5. 流量分析组件测试、完整前端测试和生产构建通过。
