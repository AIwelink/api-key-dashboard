# 每日团队鼓励开场设计

## 目标

AIwelink 管理面板在成员每天第一次进入已登录工作台时播放一次短开场，用固定文案鼓励团队。开场借鉴 AIwelink 主页“准备、聚焦、呈现、揭示”的四阶段节奏，但改为适合内部运营工具的浅色版本，不做营销页、弹窗卡片或持续装饰动画。

固定文案为：

> 世事浮沉，皆为淬炼；商海浩瀚，唯有坚毅。愿君心有赤焰，足履薄冰，终见日月新天。

## 触发规则

- 只在已经取得登录令牌和当前成员信息后判断并显示，不覆盖登录表单。
- 按成员和上海日期记录当天是否播放，存储键版本化并使用成员 ID；没有 ID 时回退到邮箱。
- 正常登录、保持登录后的首次打开，以及当天第一次刷新页面都属于“当天首次进入”。
- 开场挂载时立即写入当天标记，因此播放途中刷新不会无限重播。
- 同一成员当天退出后重新登录、再次刷新或切换页面均不再播放。
- 不同浏览器或清除浏览器存储后会独立判断；本期不增加服务端记录。

## 视觉方向

开场覆盖整个视口，不使用卡片。背景是一张连续的浅色线性渐变画布，以珍珠白 `#fffafc` 为主，加入雾蓝 `#edf7ff` 与淡玫瑰 `#ffeaf1`，文字使用深墨色 `#2d2028`，细节强调沿用品牌蓝与品牌玫红。渐变只通过一个全屏伪元素缓慢缩放和平移，不使用光球、粒子或模糊色块。

真实 AIwelink Logo 居中显示，保持原始比例和清晰度。文案位于 Logo 下方，桌面端使用 28px 中文宋体字族，移动端使用 20px；行高宽松、字距为 0。视觉上按两个完整句组换行，辅助技术读取时仍是一段连续文本。

```text
┌──────────────────────────────────────────┐
│                                      ×   │
│                                          │
│                AIwelink Logo             │
│                                          │
│       世事浮沉，皆为淬炼；商海浩瀚，      │
│       唯有坚毅。                          │
│       愿君心有赤焰，足履薄冰，            │
│       终见日月新天。                      │
│                                          │
└──────────────────────────────────────────┘
```

## 动画时间轴

总时长约 3.9 秒，所有阶段连续衔接：

1. `0-650ms` 晨光展开：浅色渐变由轻微放大状态缓慢稳定，覆盖层由透明进入。
2. `350-1250ms` 品牌聚焦：Logo 从 0.96 倍、轻微虚化和低透明度恢复到清晰原尺寸。
3. `1000-3000ms` 文案呈现：两组文字分别以 120ms 间隔，从 10px 下方柔和进入；不逐字打字，不造成阅读抖动。
4. `3000-3900ms` 工作台揭示：Logo 与文案整体轻微上移并淡出，覆盖层同步变亮并透明，底层工作台从轻微虚化恢复清晰。

动效只使用 `opacity`、`transform` 和短时 `filter`。动画结束后组件卸载，不留下持续动画、定时器或合成层。

## 交互与可访问性

- 右上角提供 36px 的关闭图标按钮，悬停提示为“跳过开场”。
- 按 `Escape` 可以立即结束，结束路径与自动播放一致。
- 开场使用 `role="dialog"`、可理解的中文标签，并把完整文案作为可访问文本。
- 播放期间锁定页面滚动；结束或组件卸载时恢复原滚动状态。
- `prefers-reduced-motion: reduce` 下不播放缩放、位移或虚化，只保留约 600ms 的静态淡入淡出，文案仍完整可读。
- 桌面和移动端均不得出现页面级横向溢出，最长一行必须在视口内换行。

## 实现边界

- 新增独立的每日判定工具和开场组件，由应用入口在认证状态下挂载。
- 复用现有 Logo 资产和全站动效变量，不引入 GSAP、Framer Motion 或新依赖。
- 不修改现有登录、权限、路由、在线状态和页面数据加载逻辑。
- 开场位于 Toast 与普通页面内容之外，避免路由切换重新挂载；关闭后现有 `.app-view-stage` 动画继续按最终状态显示。

## 测试与验收

- 单元测试覆盖上海日期、成员隔离、当天首次触发、当天重复访问不触发和次日重新触发。
- 组件测试覆盖自动阶段推进、点击关闭、`Escape`、滚动恢复和减少动态效果。
- 浏览器验证覆盖已登录首次访问、刷新不重播、桌面与 390px 手机视口、控制台错误和页面横向溢出。
- 动画截图必须能清楚看到真实 Logo、完整文案、浅色渐变和无遮挡的关闭按钮。

## 设计自检

方案的视觉签名是“晨光中出现的团队箴言”，与每天开始工作这一真实场景绑定，不是通用欢迎弹窗。浅色渐变延续现有后台的明亮品牌环境，四阶段节奏继承参考主页的构成方式，但删去了代码编辑器、黑色舞台和营销内容。唯一醒目的时刻集中在每日开场，其余时间组件完全卸载，不干扰高频操作。
