# 运营数据工作台重构设计

## 目标

重构“访问流量分析”和“运营管理”两个大型页面，移除层层卡片与重复边框，形成连续、可扫描的数据工作台，同时保留现有查询、归因、留存、收入、兑换码和配置能力。

## 已确认方向

采用 B 方案“索引工作台”，并融合 A 方案的全宽数据带：

- 页面内容超过四个主要区块时显示轻量锚点导航。
- 顶部使用紧凑筛选条、同步状态和开放式 KPI 数据带。
- 正文使用连续分区、细线和留白，不为每个区块增加卡片容器。
- 表格保留水平滚动和键盘可聚焦能力，页面负责垂直滚动。
- 指标名称旁提供可悬停、可聚焦的完整口径说明。
- 配置操作继续使用现有页签、表格和弹窗，不与分析内容混排。

## 共同视觉系统

### 容器

- 页面底色保持现有控制台背景。
- 分析正文为单一开放画布；主区块用 `1px` 分隔线和垂直间距区分。
- 卡片仅保留给模态框、错误提示、一次性兑换码结果等真正需要边界的内容。
- 圆角不超过 `6px`，正文数据分区不使用阴影。

### 信息层级

1. 页面标题、页签、同步状态和主要操作。
2. 紧凑筛选条。
3. 主要 KPI 数据带。
4. 趋势、分层、Cohort 和表格明细。
5. 数据质量、更新时间和来源说明。

### 指标口径

共享 `MetricDefinition` 组件，支持鼠标悬停与键盘聚焦。每个口径最多包含：

- 定义：指标表达的业务含义。
- 公式：明确的分子、分母或汇总表达式。
- 纳入：进入计算的数据。
- 排除：不进入计算的数据。
- 来源：表或事实域。
- 更新：同步和页面缓存频率。

组件使用按钮作为信息触发器，使用 `aria-describedby` 关联 `role="tooltip"` 内容。提示框不影响文档流，不改变 KPI 的稳定尺寸。

## 访问流量分析

### 页面索引

- 总览与趋势
- 有效归因来源
- 自然入口诊断
- 推广链接表现
- 注册归因
- 数据质量

### 顶部数据带

- 有效主页 PV
- 有效 Session UV
- 有效率
- 推广链接
- 归因注册
- 注册转化率

“数据最新”从 KPI 中移到页头/锚点状态，始终显示真实 API 时间。注册转化率按 `归因注册账号 / 有效 Session UV` 计算，分母为零时显示 `--`。

### 趋势与表格

- 在现有有效流量趋势表前增加代码原生 SVG 折线图，展示主页 PV、主页 UV 和链接 PV。
- 保留完整趋势表，不减少审计字段。
- 有效归因来源与自然入口诊断在宽屏并排，移动端单列。
- 推广链接与注册归因保持全宽表格。

## 运营管理

### 页面索引

- 经营总览
- 生命周期
- 付费与计费
- 留存 Cohort
- 价值排行
- 运营趋势
- 站点对比

索引仅在“运营概览”页签出现；内部人员、额度与兑换码、待分类继续使用原页签工作流。

### 顶部数据带

- 注册用户
- 活跃用户
- 成功调用
- 付费 / 计费用户
- 站点对应收入
- 退款

AIWeLink 继续按可核验现金收入，AIGCLink 继续按数据库调用标价。收入提示明确排除赠送兑换码和无法核验的历史兑换码。

### 生命周期与 Cohort

- 生命周期指标改为开放式 `4 x 2` 数据矩阵，移动端为两列。
- 使用流失仍统一计算余额和订阅用户，不拆分类型。
- Cohort 单元格根据留存率使用五级低饱和热力色，同时保留精确百分比。
- 未成熟观察日保持 `--`，不着色为零。

### 付费分层和趋势

- 付费与计费分层保持全部 13 个业务字段。
- 收入单元格显示站点口径副标题。
- 运营趋势与站点对比保持最新时间在前。
- 模型计费和企业客户排行继续只在 AIGCLink 可见时显示。

## 响应式行为

- `>= 1180px`：显示页面锚点；筛选尽量保持单行；指标为六列。
- `760px - 1179px`：隐藏锚点；指标为三列；并排表格改为单列。
- `< 760px`：筛选控件按两列或单列换行；指标为两列；宽表格在自身区域水平滚动。
- 所有固定格式数据区使用稳定 grid track，不因提示、加载文本或长数字改变布局。

## 非目标

- 不修改后端接口和数据库口径。
- 不改变权限、自动刷新、兑换码或内部人员的业务行为。
- 不增加新的图表依赖。
- 不把截图或位图作为产品 UI。

## 验收

- 两页在桌面和移动视口无页面级横向溢出、内容重叠或文字裁切。
- KPI、生命周期指标的口径提示可悬停、可键盘聚焦。
- 所有现有前端测试通过，新布局与口径测试先失败后通过。
- TypeScript 构建与 Vite 生产构建通过。
- 浏览器验证查询、页签、锚点、提示和表格滚动的核心路径。
