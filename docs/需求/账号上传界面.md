# 账号上传界面

账号上传页同时承担“添加账号”和“导入账号”的功能，但交互上分为两个模式：

1. 填入模式
2. 解析模式

填入模式在前，解析模式在后。默认进入填入模式。

## 模式一：填入模式

英文参数：`upload_mode = fill`

填入模式适合单个账号或少量账号。用户直接填写账号所需字段，并粘贴账号 JSON。

填入模式保存时：

- 表单字段写入 `metadata`，同时写入 `account_json.extra`，方便导出和后续查找。
- `account_type` 写入 `account_json.credentials.plan_type`。
- `2FA` 写入 `account_json.extra["2FA"]`。
- `email_session` 保存到 `metadata.email_session`；如果 `credentials.email` 不存在，也可用于补齐 `credentials.email`。
- 上传人和修改人自动绑定当前登录用户。

## 模式二：解析模式

英文参数：`upload_mode = parse`

解析模式适合批量导入。流程不是一次性直接保存所有账号，而是：

1. 用户先导入一段 JSON。
2. 系统解析出账号列表。
3. 系统按账号逐个展示。
4. 用户为每个账号补充缺失信息。
5. 用户确认后逐个保存账号。

解析模式支持的 JSON：

- 标准 sub2api export JSON：`{ "accounts": [...] }`
- 账号数组：`[{...}, {...}]`
- 单个账号对象：`{ "name": "...", "credentials": {...} }`
- 多个连续 JSON 对象：`{...} {...}`

后端只要求每个账号对象包含 `credentials`。

## 字段顺序

界面字段顺序必须按下表排列。

| 中文名称 | 英文参数 | 类型 | 必填 | 默认值 / 选项顺序 | 存储位置 |
| --- | --- | --- | --- | --- | --- |
| 邮箱和接码 session | `email_session` | 字符串 | 必填 | 无 | `metadata.email_session` 和 `account_json.extra.email_session` |
| 账号类型 | `account_type` | 选择 | 必填 | `plus`, `free`, `pro`, `other` | `metadata.account_type` 和 `account_json.extra.account_type` |
| 支付类型 | `payment_type` | 选择 | 必填 | `paypal_multi`, `paypal_single`, `no_card`, `gopay`, `other` | `metadata.payment_type` 和 `account_json.extra.payment_type` |
| 2FA | `2FA` | 字符串 | 必填 | 无 | `metadata["2FA"]` 和 `account_json.extra["2FA"]` |
| 是否绑定手机 | `phone_bound` | 布尔值选择 | 必填 | `true`, `false` | `metadata.phone_bound` 和 `account_json.extra.phone_bound` |
| 手机号 | `phone_number` | 字符串 | 选填 | 无 | `metadata.phone_number` 和 `account_json.extra.phone_number` |
| 备注 | `remark` | 字符串 | 选填 | 无 | `metadata.remark` 和 `account_json.extra.remark` |
| 状态标注 | `manual_status_label` | 字符串 | 选填 | 无 | `metadata.manual_status_label` 和 `account_json.extra.manual_status_label` |
| 账号 JSON | `account_json` | JSON 文本 | 填入模式必填，解析模式导入时必填 | 无 | `account_json` |

## 字段说明

解析模式页面下方必须展示字段说明，帮助用户逐个补信息。

| 字段 | 作用 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `email_session` | 请完整邮箱和接码 session  | 必填 | 用于后续登录账号、找回验证 |
| `account_type` | 账号订阅类型 | 必填 | 可选 `plus`、`free`、`pro`、`other`，填入模式会同步到 `credentials.plan_type`。 |
| `payment_type` | 账号支付方式 | 必填 | 可选 `paypal_multi`, `paypal_single`, `no_card`, `gopay`, `other` |
| `2FA` | 保存账号 2FA 信息 | 必填 | 填入模式会同步到 `account_json.extra["2FA"]`。 |
| `phone_bound` | 标记账号是否绑定手机 | 必填 | 布尔值，可选 `true` 或 `false`；`true` 表示已绑定手机，`false` 表示未绑定手机。 |
| `phone_number` | 记录绑定手机号 | 选填 | 当 `phone_bound = true` 时建议填写。 |
| `remark` | 备注 | 选填 | 其他任意备注信息；可补充说明 `phone_bound` 布尔值判断依据。 |
| `manual_status_label` | 状态标注（账号封禁和报错状态） | 选填 | 用于后续判断，上传时不必直接填写。 |

| `account_json` | sub2api 原始账号 JSON | 必填 | 导出和推送 sub2api 时使用，不能改结构。 |

## 交互规则

- 所有选择项默认选择第一个。
- 用户只需要在不同选项时修改。
- 上一个账号上传完成后，不重置选择项。
- 切换填入模式和解析模式时，不重置已选择的选项。
- 填入模式上传成功后，只清空字符串输入和 JSON 输入。
- 解析模式导入 JSON 后，不直接全部保存；需要逐个账号补齐缺失信息后再保存。
- 人工填写字段同时进入 `metadata` 和 `account_json.extra`；`metadata` 用于后台检索，`account_json.extra` 随账号 JSON 保留。
- 上传人和修改人自动绑定当前登录用户，不允许前端手动填写。
