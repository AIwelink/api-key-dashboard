# AIWeLink 增长数据看板 V1

## 一、核心目标

为每个具体推广来源生成一条唯一链接。用户通过链接进入网站后，后台能够看到他是否注册、是否调用、是否充值、是否二次充值、是否继续调用。

这样可以判断哪条帖子、哪个群或哪个推荐人带来的用户更有效，并复用有效来源。

## 二、需要开发什么

### 1. 生成唯一推广链接

后台可以为每个具体来源单独生成链接，并写清：

- 来自哪个平台；
- 来自哪条帖子、哪个群或哪个推荐人；
- 由谁负责推广；
- 链接生成时间。

来源包括但不限于：

- 小红书某一条帖子；
- V2EX 某一条帖子；
- Linux 论坛某一条帖子；
- Telegram 某一个群；
- 微信某一个群；
- 某一位熟人推荐；
- 其他论坛或渠道中的具体入口。

不同帖子、群和推荐人必须使用不同链接，不能只按“小红书”“论坛”笼统统计。

### 2. 查看每条链接带来的结果

每条推广链接下直接显示：

- 点击人数；
- 注册账号数；
- 完成过成功调用的账号数；
- 完成过充值的账号数；
- 完成过二次充值的账号数；
- 首次调用后仍继续调用的账号数；
- 充值金额和退款金额。

点击上述数字，可以查看对应账号名单。

### 3. 查看单个账号的后续行为

进入账号详情后，可以看到：

- 他通过哪条推广链接进入；
- 是否注册及注册时间；
- 是否成功调用及首次调用时间；
- 是否充值、首次充值时间和金额；
- 是否二次充值、二次充值时间和金额；
- 后续是否继续调用及最近调用时间；
- 是否发生退款。

## 三、统一判断标准

- 注册成功才算注册，只有点击不算注册；
- 成功获得模型响应才算调用，失败请求不算；
- 两笔独立且成功到账的充值才算二次充值；
- 首次成功调用后再次成功调用，才算继续调用；
- 团队内部账号和测试账号不进入正式统计；
- 一个账号只能归入一条推广链接，避免重复计算。

## 四、验收方式

生成一条“某篇小红书帖子”的推广链接，用测试账号完成：

```text
点击链接
→ 注册
→ 成功调用
→ 第一次充值
→ 第二次充值
→ 再次成功调用
```

后台必须做到：

1. 这名账号出现在该小红书帖子的链接下；
2. 注册、调用、充值、二次充值和继续调用均显示为已完成；
3. 点击每项结果可以找到该账号；
4. 账号详情中的来源和行为时间线与实际记录一致。

## 五、完成标准

V1 完成后，团队必须能直接回答：

> 哪个具体平台、帖子、群或推荐人带来了用户，这些用户后来是否注册、调用、充值、二次充值并继续使用。
